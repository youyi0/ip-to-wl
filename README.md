功能说明
1、使用一个 VLESS 节点与多个“优选域名（IP）：端口#名称”生成多个新节点
输入一个完整的 VLESS 节点。

输入多个“域名或 IP：端口#名称”。

自动替换原节点的域名或 IP 与端口，保留原节点全部参数。

自动生成多个新的 VLESS 节点。

2、从多个 VLESS 节点中提取“域名（IP）：端口#名称”
输入多个 VLESS 节点。

自动提取每个节点的域名或 IP、端口、名称。

输出为“域名（IP）：端口#名称”格式。

3、多个节点或多个“优选域名（IP）：端口#名称”使用换行分割
多行输入自动逐行处理。

支持批量生成与批量提取。

支持任意数量的节点或优选域名。
